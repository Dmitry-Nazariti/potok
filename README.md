# Поток

Локальный учёт финансового потока. Деньги, зарплата, бюджет и агенты, которые говорят, что менять в тратах. База не уходит с компьютера.

Это не банк, не налоговый совет и не рекомендация по инвестициям. Цифры считаются из ваших операций. Решение остаётся за вами.

## Запуск

Нужен Node.js 22 или новее. Сторонние пакеты не ставятся.

Дважды щёлкните `start.bat` или в этой папке выполните:

```bash
npm start
```

Откроется [http://127.0.0.1:4317](http://127.0.0.1:4317). Сервер слушает только этот компьютер.

На первом экране можно начать свой учёт или посмотреть вымышленный пример: зарплата 10-го, аренда 1-го (раньше выплаты), кафе сверх лимита, тонкий остаток до зарплаты.

## Что умеет

- Счета: карта, наличные, накопления. Накопления не входят в «можно потратить».
- Операции, переводы, категории, лимиты.
- Зарплата и другие повторы. Кнопка «Зарплата пришла» пишет факт и сдвигает график. Аванс и премия график не трогают.
- Подход 50/30/20 и другие рамки: нужды, желания, накопления. Доли можно менять, когда подход перестал сходиться с жизнью.
- Цели и перевод в подушку.
- Импорт CSV (`Дата;Сумма;Описание` или приход/расход). Пример: `samples/statement.csv`.
- Экспорт JSON из настроек.
- Прогноз на 60 дней: повторы по датам, обычные траты по вашему темпу.

«Можно потратить» — это не остаток на карте. Из свободных денег вычитаются буфер и платежи, которые случатся раньше следующей зарплаты.

## Агенты

Все шестеро работают без интернета:

| Агент | Смотрит |
| --- | --- |
| Касса | Сколько реально можно потратить до зарплаты и хватает ли выплаты на выбранный подход |
| Бюджет | Факт против лимита и темпа месяца |
| Подход | Нужды, желания и накопления против вашей рамки |
| Прогноз | Кассовый разрыв на горизонте 60 дней и стоимость подписок |
| Аномалии | Нетипичные чеки и возможные двойные списания |
| Категории | Операции без категории, по вашим прошлым пометкам |

Рекомендацию можно принять: закрепить правило, сменить подход, поставить буфер или разложить категории. Скрытая рекомендация не возвращается две недели.

Кнопка «Спросить модель» необязательна. Модель получает сводку, а не всю базу, и не меняет цифры. Ключ хранится в `data/potok.sqlite`. Подойдёт любой OpenAI-совместимый адрес: OpenAI, OpenRouter, LM Studio, Ollama с `/v1`.

## Данные

`data/potok.sqlite` — единственное хранилище. Папка в `.gitignore`. Чтобы начать заново, в настройках есть «Стереть всё».

Проверка расчётов:

```bash
npm run check
```
